# Phase 7C：冻结控制器的多温度 DFN 外推验证计划

## 1. 当前基础

Phase 7A、Phase 7B-0 和 Phase 7B-1 已完成并合并到 `main`。

当前已经在 25 ℃ Chen2020 DFN 上严格通过的控制架构为：

\[
\boxed{
\text{ANN 策略}
+
\text{电流/斜率投影}
+
\text{在线电压残差安全层}
}
\]

Phase 7B-1 独立确认集的核心结果如下：

| 指标 | 结果 |
|---|---:|
| 独立确认初态 | 24 个 |
| 安全 ANN 最高 DFN 电压 | 4.189463 V |
| 五种子平均电流 NRMSE | 0.1785%–0.2086% |
| 最大平均充电时间偏差 | 0.9975% |
| 目标到达率 | 100% |
| 电流、斜率和电压违约 | 0 |
| 电压—斜率空区间 | 0 |
| 最低在线加速 | 170.9 倍 |
| 完整测试 | 112 项全部通过 |

一步电压安全层已经足以解决 25 ℃下的 2RC—DFN 电压预测失配，暂不需要短时域安全 MPC。

目前尚未证明的是：这套冻结于 25 ℃的控制器和安全合同，在 15 ℃和 30 ℃ Chen2020 DFN 上是否仍然成立。

## 2. Phase 7C 的研究问题

Phase 7C 只回答以下问题：

> 在不重新训练 ANN、不重新生成教师数据、不调整现有安全层参数的条件下，25 ℃建立的控制架构能否外推到 15 ℃和 30 ℃ DFN，并继续保证控制精度、充电性能和物理约束？

需要分别判断：

1. ANN 是否仍能逼近同一冻结 MPC；
2. 电流和斜率投影是否继续严格有效；
3. 25 ℃建立的电压残差增长界能否跨温度使用；
4. 一步电压安全层是否仍有足够的制动提前量；
5. 15 ℃低温极化是否导致控制策略外推失效；
6. 30 ℃条件下是否出现超过 35 ℃的热安全问题；
7. 安全层的介入比例和充电时间代价是否显著增加。

Phase 7C 是多温度鲁棒性审计，不是 Level 4。Level 4 意味着把温度状态和温度约束加入控制器并重新构造控制问题；Phase 7C 暂不这样做。

## 5. Phase 7C-1：多温度闭环实验矩阵

每个温度运行两类主要控制器：

1. 冻结安全 MPC 接入 DFN；
2. 冻结安全 ANN 接入 DFN。

二者均使用相同的：

- 电流/斜率投影；
- 在线电压残差修正；
- 一步电压安全限制；
- DFN初态和环境温度合同。

建议实验规模如下：

| 控制器 | 15 ℃ | 30 ℃ | 合计 |
|---|---:|---:|---:|
| 安全 MPC→DFN | 24 | 24 | 48 |
| 安全 ANN→DFN，五种子 | \(24\times5\) | \(24\times5\) | 240 |
| 总计 | 144 | 144 | 288 |

安全 MPC 用于判断 2RC模型、安全层和 DFN 温度失配；安全 ANN 与安全 MPC 的配对差异用于判断 ANN 策略本身是否退化。

## 6. 控制与安全定义

充电电流取正，单位为 A。

电流和斜率约束给出的基础可行区间为：

\[
I_k^-
=
\max\left(0,I_{k-1}-2\right),
\]

\[
I_k^+
=
\min\left(10,I_{k-1}+2\right).
\]

当前测量电压残差为：

\[
e_{V,k}
=
V_{\mathrm{meas},k}
-
\hat V_{\mathrm{2RC},k},
\]

其中：

- \(V_{\mathrm{meas},k}\) 为 DFN 在控制时刻 \(k\) 的端电压，单位 V；
- \(\hat V_{\mathrm{2RC},k}\) 为 2RC 模型在同一时刻的预测电压，单位 V。

修正后的下一步电压预测为：

\[
\hat V_{k+1}^{\mathrm{corr}}(I)
=
\hat V_{k+1}^{\mathrm{2RC}}(I)
+
e_{V,k}
+
\Delta V_{\mathrm{guard}}.
\]

电压允许的最大电流为：

\[
I_{V,k}^{\max}
=
\max
\left\{
I\in[0,10]:
\hat V_{k+1}^{\mathrm{corr}}(I)
\leq 4.2
\right\}.
\]

最终可行区间为：

\[
\mathcal U_k
=
\left[
I_k^-,
\min\left(I_k^+,I_{V,k}^{\max}\right)
\right].
\]

若出现：

\[
I_{V,k}^{\max}<I_k^-,
\]

则判定为电压—斜率空区间。此时禁止突破斜率约束或使用未申明的紧急硬裁剪来制造通过结果。

## 8. 温度安全的解释边界

Phase 7C 不把温度状态加入 ANN 或 MPC，但 DFN 平均温度必须作为独立安全门槛审计：

\[
T_{\max}
\leq
35\ ^\circ\mathrm{C}.
\]

如果电流、斜率和电压均通过，但30 ℃下温度超过35 ℃，不能将其表述为“ANN拟合失败”。

正确结论应为：

> 当前 ANN 策略、电流投影和电压安全层能够维持电气约束，但控制架构缺少热约束感知，因此尚不适用于该高温充电条件。

只有得到这一证据后，才考虑建立独立温度安全层或进入包含热状态和热约束的后续阶段。

## 9. 失败归因规则

| 实验现象 | 主要归因 | 下一步 |
|---|---|---|
| 安全 MPC 和安全 ANN 均通过 | 现有架构具备多温度零调参外推能力 | 冻结 Phase 7C 证据链 |
| 安全 MPC 通过、ANN失败 | ANN策略发生温度分布外退化 | 审计状态充分性和策略输入，不立即重训 |
| MPC和ANN同时电压失败 | 25 ℃电压安全合同不能跨温度使用 | 建立温度相关残差增长界 |
| 出现电压—斜率空区间 | 一步安全层制动太晚 | 进入2～5步短时域安全预测 |
| 电气约束通过但温度超过35 ℃ | 缺少热安全控制 | 单独规划温度感知安全层 |
| 安全通过但充电时间显著增加 | 电压安全层过于保守 | 使用新的开发集优化裕量 |
| 15 ℃通过、30 ℃失败 | 高温热约束或高温模型失配是主要边界 | 优先开展高温诊断 |
| 30 ℃通过、15 ℃失败 | 低温极化和动力学失配是主要边界 | 优先开展低温模型诊断 |

## 10. 严格停止条件

出现以下任一情况时，应停止继续扩大实验范围：

1. 任一温度出现真实电压越界；
2. 任一温度出现电压—斜率空区间；
3. 最大平均温度超过35 ℃；
4. 安全 MPC 本身无法到达目标；
5. 安全 ANN 相对安全 MPC 的 NRMSE 超过1%；
6. 到达率低于100%；
7. 计算加速低于100倍；
8. 出现未解释的 fallback、求解失败或异常振荡；
9. 冻结工件哈希不匹配；
10. 实验回放合同不能保证相同初态和相同控制更新时刻。

停止后只诊断触发失败的单一因素，不进入参数扰动、噪声、老化或跨电池实验。

---

## 11. 本阶段禁止事项

Phase 7C 第一轮禁止：

- 重新训练 ANN；
- 新增 MPC 教师数据；
- 修改 ANN 输入或网络结构；
- 修改五个随机种子；
- 调整 25 ℃电压残差增长裕量；
- 使用15/30 ℃确认集调参后，再用同一确认集声明通过；
- 同时加入参数扰动、测量噪声、老化和跨电池变化；
- 把安全层降流造成的时间变化误判为ANN拟合退化；
- 把30 ℃热越界简单归因于ANN；
- 为消除电压违约而突破2 A/5 s斜率限制。

## 12. 通过后的下一步

如果15 ℃和30 ℃均严格通过，可以形成以下阶段结论：

> 冻结于25 ℃的 ANN 策略在不重新训练的情况下，通过电流/斜率投影和在线电压残差安全层，实现了15–30 ℃ Chen2020 DFN闭环控制，并同时满足控制精度、目标到达、电气安全、热安全和在线计算门槛。

此后建议只选择一条路线继续：

### 路线A：降低安全层保守性

目标是降低当前约4.69%的相对充电时间代价。

要求：

- 不能使用 Phase 7B-1 或 Phase 7C 的独立确认集重新调参；
- 另建开发集估计随SOC、温度或残差状态变化的增长界；
- 调参完成后重新生成独立确认集；
- 安全门槛不得放宽。

### 路线B：逐项增加参数扰动

建议顺序：

1. 容量偏差；
2. 欧姆内阻偏差；
3. 极化参数偏差；
4. 热参数偏差；
5. SOC估计误差；
6. 电压和温度测量噪声；
7. 老化参数；
8. 跨电池验证。

每次只增加一种复杂度，并保留相同的停止条件和独立确认原则。

Phase 7C 通过前，不应进入上述两条路线。
