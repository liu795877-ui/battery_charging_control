# 第二阶段降阶模型定义

## 1. 目的和适用范围

第二阶段把 Chen2020 DFN 高保真虚拟电芯降阶为适合 MPC 快速预测的二阶 RC
电模型和核心—表面双节点热模型。当前参数仅面向 25 ℃、10%–80% SOC 附近、
0–2C 充电激励；项目统一规定充电电流为正。

## 2. 符号

| 符号 | 含义 | 单位 |
|---|---|---:|
| \(z\) | SOC | 1 |
| \(I\) | 充电电流 | A |
| \(Q_n\) | 标称容量 | Ah |
| \(U_{oc}(z)\) | 开路电压 | V |
| \(R_0\) | 欧姆内阻 | ohm |
| \(v_1,v_2\) | 快、慢极化压升 | V |
| \(R_1,R_2\) | 极化电阻 | ohm |
| \(C_1,C_2\) | 极化电容 | F |
| \(T_c,T_s,T_a\) | 核心、表面、环境温度 | degC |
| \(C_c,C_s\) | 核心、表面热容量 | J/K |
| \(R_{cs},R_{sa}\) | 核心—表面、表面—环境热阻 | K/W |
| \(q\) | 输入热功率 | W |

## 3. 二阶 RC 电模型

在库仑效率取 1、标称容量不随温度和老化变化的第一版假设下：

\[
\frac{dz}{dt}=\frac{I}{3600Q_n}.
\]

两个极化支路满足：

\[
\frac{dv_j}{dt}=-\frac{v_j}{R_jC_j}+\frac{I}{C_j},
\qquad j\in\{1,2\}.
\]

令 \(\tau_j=R_jC_j\)，端电压为：

\[
V=U_{oc}(z)+R_0I+v_1+v_2.
\]

由于本项目规定充电电流为正，充电时欧姆项和极化项表现为相对 OCV 的压升。

## 4. 双节点热模型

第一版忽略可逆熵热，用电模型预测的不可逆损耗近似热源：

\[
q=k_q\max\left[I\left(V-U_{oc}\right),0\right],
\]

其中 \(k_q\) 是用于吸收未建模热源和参数误差的热增益。热状态方程为：

\[
C_c\frac{dT_c}{dt}=q-\frac{T_c-T_s}{R_{cs}},
\]

\[
C_s\frac{dT_s}{dt}=\frac{T_c-T_s}{R_{cs}}-\frac{T_s-T_a}{R_{sa}}.
\]

Chen2020 集总热模型只给出平均温度，所以固定核心热容量比例 \(\alpha=0.8\)：

\[
C_c=\alpha C_{th},\qquad C_s=(1-\alpha)C_{th},
\]

并使用下式与 DFN 平均温度进行拟合和验证：

\[
T_{avg}=\alpha T_c+(1-\alpha)T_s.
\]

因此 \(T_{avg}\) 是已验证输出，而 \(T_c\) 与 \(T_s\) 仍是潜在内部状态，不能
在没有空间温度观测的情况下宣称已分别验证。

实际第一版辨识中，\(R_{cs}\) 命中优化下限，说明现有集总温度数据无法支持
可靠的核心—表面温差辨识，双节点模型退化为接近单一温度。后续若要把核心
温度用于硬安全约束，必须加入空间热模型数据或实测核心/表面双温度数据。

## 5. 初始条件与数值方法

每条虚拟试验从指定 SOC 和 25 ℃平衡初态开始：

\[
v_1(0)=v_2(0)=0,
\qquad T_c(0)=T_s(0)=T_a=25\ ^\circ\mathrm{C}.
\]

电模型对每个恒流采样区间使用解析零阶保持离散式；热模型使用矩阵指数精确
离散化。这样避免显式欧拉法在热时间常数较小时产生数值不稳定。
