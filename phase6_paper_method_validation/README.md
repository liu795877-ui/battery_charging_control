# Phase 6：论文方法迁移验证

本目录定义独立于 Phase 1–5 的论文方法迁移实验。目标不是声称完全复现原论文的 EHM 案例，而是验证其核心流程能否迁移到当前 Chen2020/2RC/双节点热模型：

1. 使用 Hammersley＋边界全因子设计采样初始状态；
2. 对每个初始状态求解一条 8 步约束 MPC 轨迹；
3. 将轨迹展开为当前状态到下一步最优电流的数据；
4. 训练不带安全过滤器的三隐层 DNN 显式控制律；
5. 先进行 25 ℃ 名义 DFN 闭环对照；
6. 只有名义门槛通过后，才运行 15/30 ℃ 和 Phase 5A 压力测试。

## 与原论文的差异

- 原论文 EHM 案例的完整状态由 SOC、CSC 和温度确定；本项目使用 SOC、两个 2RC 极化电压、平均温度和上一时刻电流。
- 原论文 EHM 采样周期为 1 min；本项目保持已经验证的 5 s 控制周期。
- 原论文使用其 EHM 健康约束；本项目使用现有 4.20 V、35 ℃、10 A 和 2 A/5 s 约束。
- 因此这里属于“方法迁移验证”，不是数值逐项复现。

论文依据：Shokry et al., *Computers & Chemical Engineering* 199 (2025) 109096，DOI: 10.1016/j.compchemeng.2025.109096，尤其是 Section 3 和 EHM case study 的 Figure 19–20。
